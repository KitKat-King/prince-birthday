# Only UI No UX Max Pro Ultra Rules

## Core Philosophy: Pure Frontend UI
- **Zero Backend**: Do not create or configure backend servers, databases, or API routes. The project is strictly a client-facing frontend.
- **Pure UI Focus**: Focus exclusively on visual design, typography, spacing, component architecture, responsive layouts, and motion design.
- **No UX Overhead**: Bypasses heavy UX research phases, user personas, and theoretical journey maps. Directly implement high-fidelity visual interfaces and components.
- **Target Deployment**: Vercel (static / frontend Next.js). Ensure all code is cleanly buildable and deployable on Vercel.

## Tech Stack
- **Languages**: HTML5, CSS3, modern JavaScript / JSX
- **Styling**: Tailwind CSS (utility classes), Bootstrap (when specific components/utilities are requested), custom CSS3
- **Framework & Libraries**: Next.js (App Router), React
- **Animation**: Framer Motion (use for smooth transitions, hover effects, stagger animations, and scroll reveals)

## Available Workspace Skills (.agents/skills/)
- `ui-ux-pro-max`: Query styles, palettes, font pairings, and animation presets using `python3 .agents/skills/ui-ux-pro-max/scripts/search.py "<query>" --domain <domain>`.
- `ui-styling`: Tailwind and component styling guidance.
- `design-system`: Color palettes, design tokens, and spacing scales.
